# Open-source game sources selected for Al-Molook

This file records third-party game sources selected for evaluation/integration.

- Backgammon: quasoft/backgammonjs — MIT. https://github.com/quasoft/backgammonjs
- Dominoes: ppyne/dominoes — BSD-3-Clause. https://github.com/ppyne/dominoes/
- Ludo: RoJac88/ludo-js — MIT. https://github.com/RoJac88/ludo-js

Integration rule: third-party source must remain attributable and its license requirements must be preserved. Do not mark a game as integrated until its actual game engine is wired and tested inside the app.
