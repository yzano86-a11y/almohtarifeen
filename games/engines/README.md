# محركات الألعاب الموحدة — المحترفين

هذا المجلد هو طبقة التكامل المشتركة بين ألعاب المحترفين. لا يتم إدخال كود طرف ثالث هنا إلا بعد التحقق من الترخيص.

## واجهة المحرك الموحدة

كل محرك لعبة يجب أن يعرّض العمليات التالية:

- `createGame(config)`
- `joinGame(gameId, playerId)`
- `getState(gameId, playerId)`
- `applyAction(gameId, playerId, action)`
- `getLegalActions(state, playerId)`
- `isFinished(state)`

## سياسة الدمج

1. الترخيص يجب أن يسمح بالاستخدام والتعديل التجاري.
2. لا تُنقل أصول أو شعارات أو بيانات من تطبيقات تجارية.
3. يتم عزل كود الطرف الثالث عن Supabase وواجهة المحترفين بواسطة adapter.
4. Realtime والغرف والمصادقة تبقى ملكاً لبنية المحترفين.
5. كل لعبة تحتاج اختبارات قواعد قبل إعلانها جاهزة.

## المحركات المرشحة حالياً

- طاولة / محبوسة: backgammonjs (MIT) — يحتاج adapter وقواعد محبوسة.
- شطرنج: flaviengibs/chess (MIT) — يحتاج adapter.
- أونو: card-room أو uno-online (MIT) — يحتاج فحص كود نهائي قبل إدخال المصدر.
- دومينو: ppyne/dominoes (BSD-3-Clause) — يحتاج طبقة Multiplayer.
- لودو: ludo-js (MIT) — يحتاج Realtime واختبارات.

الألعاب الأخرى تبقى على محرك المحترفين إلى أن يوجد أساس مفتوح موثوق ومناسب.
