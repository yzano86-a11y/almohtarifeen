# v1.6 — Android-ready

هذه النسخة مجهزة كـ Capacitor project:
1. `npm install`
2. `npm run cap:sync`
3. `npx cap open android`
4. من Android Studio: Build > Generate Signed Bundle / APK.

App ID:
`com.almohtarifeen.tarneeb`

مهم: إنشاء APK موقّع فعلياً يتطلب Android SDK/Gradle وKeystore في بيئة بناء Android.
