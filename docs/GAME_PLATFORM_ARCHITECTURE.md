# المحترفين في الطرنيب — منصة الألعاب

## المبدأ
التطبيق منصة ألعاب واحدة. كل لعبة لها محرك وقواعد واختبارات مستقلة، ويمكن تنزيل أصول/وحدة اللعبة عند الطلب عندما تدعم بنية Android ذلك، بدون التضحية بالأداء أو الاستقرار.

## مركز الألعاب
كل بطاقة لعبة تعرض حالة واضحة:
- متاحة الآن
- لعب تجريبي
- أونلاين
- جارٍ التحضير
- مثبتة/جاهزة

لا تظهر لعبة كـ«جاهزة» إذا كانت مجرد واجهة أو زر.

## بيانات التحليلات
نقيس بشكل مشروع:
- game_view
- install_or_download
- game_start
- game_finish
- session_duration
- matchmaking_success
- retention

لا نستخدم هذه الأحداث لتضخيم أرقام Google Play أو التحايل على قياسات المتجر.

## عقد اللعبة
كل لعبة يجب أن توفر:
- rulesVersion
- deterministic state model حيثما أمكن
- legalMove validation
- scoring engine
- bot policy
- online state synchronization
- reconnect/resume
- result verification
- QA checklist

## ترتيب الأولوية
1. طرنيب — تثبيت المحرك والـAI والأونلاين.
2. محبوسة — محرك وقواعد واختبارات كاملة.
3. طاولة.
4. دومينو.
5. جاكارو.
6. بقية الألعاب بعد اعتماد كل لعبة على حدة.

## معيار الإطلاق
لا تنتقل اللعبة إلى الإنتاج إلا بعد نجاح الاختبارات الوظيفية، القواعدية، الأونلاين، الأمان، الأداء، وتجربة الهاتف.
